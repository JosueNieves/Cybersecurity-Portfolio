Networking Fundamentals

Lesson 1: What Is a Computer Network?

Definition

A network is a system that allows devices to exchange information and share resources using agreed-upon communication rules (protocols).

Why Networks Exist?

Networks solve several problems:

Sharing files
Sharing printers
Communicating with other people
Accessing cloud services
Streaming video
Online gaming
Remote work
Security monitoring
Backups

Without networks, every computer would be isolated.

- Data is transmitted as packets.
  
- What Is Data?

Everything on a computer eventually becomes binary.

Letters, numbers, pictures, videos, passwords—they're all represented as 0s and 1s.

Example:

A = 01000001

Your computer doesn't think in English.

It thinks in electrical states that represent binary values.
  
- What Is a Packet?

Imagine you want to mail a 500-page book.

You don't put the whole book into one envelope.

Instead, you split it into many pages and send them separately.

Networks work similarly.

A large file is divided into packets.

Each packet contains:

- Source address
- Destination address
- Data
- Error-checking information

The receiving computer reassembles the packets into the original file.
